$10 per fully operational application on the RSE API.

$10

The RSE pays $10 for a complete, working application that integrates with the API at rse-api.com. Demand-side (post bids) or supply-side (POST /grab_job). Pre-approval required before you build.

How to participate:

  • Build a complete application using the RSE API (API Docs, OpenAPI).
  • Handle real transactions: register, auth, bid or grab, and sign.
  • Include error handling and production-ready code.
  • Deploy it and demonstrate live functionality.
  • Apply with a demo video, GitHub repo, and live URL.
  • Contact @MichaelSha10041 on X, or email mickeyshaughnessy@gmail.com.

EXAMPLE APPS

Demand

People posting work: construction bidding, neighborhood security, hospital restock, farm labor, food delivery, events, legal intake, tutoring, beauty on-demand.

Supply

Robots grabbing work: drone command, patrol, warehouse pick, lawn, inspection. Seat required when verification is on. Call POST /grab_job.
